# Nimbus Swing Design System — Web Edition

Java Swing Nimbus Look & Feel을 React와 Tailwind CSS v4로 재현한 실행형 웹 카탈로그입니다.

## 실행

```powershell
npm install
npm run dev
```

로컬 주소는 `http://localhost:3000`입니다.

## 검증

```powershell
npm run lint
npm test
```

`npm test`는 배포 빌드와 서버 렌더링, 디자인 토큰 및 상호작용 계약을 확인합니다.

## 주요 화면

- Foundations — 색상, 타이포그래피, 간격, 컴포넌트 상태
- Controls — 입력, 선택, 버튼, 슬라이더
- Data views — 트리, 정렬 가능한 표, 활동 목록, 컨텍스트 메뉴
- Feedback — 진행 상태와 의미별 메시지
- Dialogs — 정보·확인·파일·색상 대화상자 및 내부 창
